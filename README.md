# 🍳 Кулинарная книга

Веб-приложение на Django для публикации и просмотра рецептов.

## Технологии
- Python 3.14
- Django 6.1
- SQLite
- Bootstrap 5

## Функционал
- Список рецептов с фильтром по категориям
- Карточка рецепта: ингредиенты, шаги, время, сложность
- Комментарии к рецептам
- Оценки (1–5 звёзд)
- Регистрация и авторизация
- Добавление своих рецептов
- Админ-панель `/admin/`

## Модели
- `Category` — категории блюд
- `Recipe` — рецепты
- `Comment` — комментарии
- `Rating` — оценки (уникально для пары рецепт+пользователь)

## Запуск
```bash
pip install django pillow
python manage.py migrate
python manage.py createsuperuser
python manage.py runserver
